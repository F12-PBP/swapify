## Description
Swapify adalah platform sosial yang memungkinkan pengguna untuk menawarkan dan menukar pakaian bekas yang masih layak pakai kepada pengguna lain. Platform ini bertujuan untuk memperpanjang siklus penggunaan pakaian sekaligus mendorong penerapan gaya hidup berkelanjutan melalui konsep slow fashion dan reuse.

## Peran Pengguna
Pengguna dapat membuat profil, menambahkan lokasi, serta memosting pakaian bekas yang ingin ditukarkan. Pengguna lain dapat melihat katalog, mengajukan permintaan pertukaran dengan menawarkan pakaian miliknya, lalu berkomunikasi melalui chat setelah permintaan diterima.

Pertukaran dapat dilakukan melalui pertemuan langsung atau jasa ekspedisi. Untuk pengiriman, pengguna dapat memasukkan penyedia jasa dan nomor resi serta mengonfirmasi penerimaan barang. Setelah transaksi selesai, kedua pengguna dapat memberikan review dan rating.
