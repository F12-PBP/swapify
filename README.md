## Description

**Swapify** adalah platform sosial yang memungkinkan pengguna untuk menawarkan dan menukar pakaian bekas yang masih layak pakai kepada pengguna lain.

Platform ini bertujuan untuk memperpanjang siklus penggunaan pakaian sekaligus mendorong penerapan gaya hidup berkelanjutan melalui konsep slow fashion dan reuse.

## Peran Pengguna

Pengguna dapat membuat profil, menambahkan lokasi, serta memosting pakaian bekas yang ingin ditukarkan.

Pengguna lain dapat melihat katalog pakaian yang tersedia dan mengajukan swap request dengan menawarkan pakaian miliknya sendiri.

Setelah permintaan diterima, kedua pengguna dapat berkomunikasi melalui fitur chat untuk menentukan mekanisme pertukaran.

Pertukaran dapat dilakukan melalui:

- Pertemuan langsung
- Jasa ekspedisi

Untuk pertukaran menggunakan ekspedisi, pengguna dapat memasukkan informasi penyedia jasa pengiriman dan nomor resi.

Setelah kedua pengguna menerima barang yang dipertukarkan, transaksi dapat dikonfirmasi sebagai selesai. Kedua pengguna kemudian dapat memberikan review dan rating terhadap pengalaman pertukaran tersebut.
